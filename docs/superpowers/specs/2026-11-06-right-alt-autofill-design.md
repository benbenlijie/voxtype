# 右侧 Alt 与鼠标共用安全回填

用户已同意：由辅助程序接管右侧 Alt，关闭 Voxtype 内置同名监听，输出默认保持 clipboard；不安装新的全局按键工具。

- 按下右侧 Alt 时记住当前键盘焦点所属窗口，不要求鼠标在输入框或窗口中。仅观察右侧 Alt 的按下/松开，不保存其他键的内容。
- 独立的键盘录音状态与鼠标互斥，重复按下不重启录音，松开只停止一次。录音最长 60 秒；锁屏、监听失败时取消自己启动的录音。
- 共用现有每次录音的私有文件、剪贴板拥有者核对、窗口焦点核对、输入事件确认和一次性粘贴。目标改变只复制；原窗口普通应用限制（无法确认同窗内输入框或密码框）保持，不夸大为精确输入框识别。
- 等待目标捕获最多 0.5 秒，再开始录音。无法捕获时保持默认剪贴板输出。录音后不按回车。
- 默认不接管键盘；新增显式 --right-alt 选项。本机配置启用该选项后才关闭原内置热键。
- 验证：先失败后通过的测试、全部原有测试、独立 Xvfb 中实际按键/窗口/剪贴板测试；真实麦克风和用户应用需与隔离测试区分。
