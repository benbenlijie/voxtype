# 右侧 Alt 安全回填实施计划

目标：右侧 Alt 与鼠标长按共用同一套安全回填；失败保留剪贴板，不自动发送。

1. 为 listener 的键盘状态、重复按下、松开、忙碌、锁屏和鼠标互斥写失败测试。
2. 在 Autofill / fill_worker / WindowTarget 增加按当前焦点捕获的显式分支，不改变鼠标捕获和最终粘贴许可。
3. listener 增加 --right-alt；在 RECORD 读取线程中仅区分该键，其他按键只使回填失效。主循环等待捕获、检查物理释放并限制时长。
4. 运行全部原有测试以及独立 Xvfb 实际键盘事件、剪贴板、粘贴接收测试；检查不重复输出、焦点变化仅复制。
5. 备份本机文件，安装已验证源码；服务参数加 --right-alt；Voxtype 默认 clipboard 并关闭内置热键。检查服务日志。真实语音由用户最终确认。

限定修改范围：extras/mouse-hold 及上述文档。本机部署只改同目录已变更文件、voxtype-mouse-hold.service 和 config.toml。
