# 安全与兼容性边界

## 核心原则

- Voxtype 负责录音、识别和文字输出；可选鼠标助手只通过 `voxtype record start/stop/cancel` 控制核心。
- 鼠标全局监听必须由用户明确启用，不是安装后的默认行为。
- 识别结果不自动发送、不按回车，也不因为焦点变化而强行切换窗口。
- 不把识别原文、聊天内容或模拟按键内容写入日志。
- 安装器和卸载器只操作用户目录中的项目配套文件；不覆盖 Voxtype 的配置、模型或系统文件。

## 鼠标操作的预期边界

鼠标配套当前实现的约定如下；通过单元测试不代表已通过真实桌面验证：

| 情况 | 预期行为 |
| --- | --- |
| 鼠标左键原地按住约 0.5 秒 | 开始录音；短按或等待期间明显移动则不启动 |
| 录音过程中距按下位置超过 100 像素 | 取消录音，不进入识别或回填 |
| 松开鼠标左键 | 结束录音并等待识别 |
| 普通应用且目标焦点可安全确认 | 最多尝试一次 `Ctrl+V`；不发送回车 |
| 终端 | 使用适配终端的粘贴方式，不假设 `Ctrl+V` 一定等于粘贴 |
| 目标窗口或输入焦点无法安全确认 | 只保留剪贴板结果，不尝试粘贴 |

全局鼠标监听可能与桌面操作及其他输入工具相互影响。若使用者不能确认当前窗口和焦点安全，应停用鼠标服务，而不是依赖自动粘贴。

## 平台与应用兼容

第一版鼠标配套的目标范围是 Linux X11。Wayland、macOS、Windows 均未验证，不能宣称支持。不同桌面、终端、浏览器、聊天软件和输入框也必须分别实测；一次模拟测试或一个应用中的成功都不能代表普遍兼容。

真实应用验收仍未完成。中文处理目前可进行繁体转简体及空格修整；标点恢复模型的正式来源和许可尚未核实，所以模型不随项目提供，也不由安装器下载。缺少模型时不会阻止其他文字处理步骤。

## 如何停用

停止本次会话中的鼠标服务：

```sh
systemctl --user stop voice-suite-mouse.service
```

禁止其再次启动：

```sh
systemctl --user disable --now voice-suite-mouse.service
```

移除已安装的项目配套文件：

```sh
bash scripts/uninstall-voice-suite.sh
```

卸载只移除清单内的项目文件，并先尝试停止、禁用对应服务。Voxtype 配置、模型和其他用户数据会保留；`.bak-*` 备份也会保留，需由用户自行检查。
