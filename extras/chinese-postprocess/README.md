# Voxtype 中文语音后处理

这是一个可选的 Voxtype 输出后处理配套。它从标准输入读入转写文本，并在失败时尽量保留可用文本；它不修改 Voxtype 的 Rust 识别路径。

## 当前状态

- 简体转换依赖 `opencc-js@1.4.2`。
- 命令会尝试加载 `opencc-js@1.4.2`；依赖未安装或转换失败时，原文仍会输出。
- 标点恢复是可选的：用户可安装并自行配置模型适配程序，项目不会提供或下载模型。
- 已配置的适配程序接收简体文字作为标准输入，并将补好标点的文字写到标准输出。
- 未配置适配程序时，只进行繁体转简体及保守空格修整；不下载、不联网。
- 空输入直接原样输出。
- 模型推理失败、返回空结果或依赖不可用时，保留已经完成的简体转换；命令入口失败时回退到输入原文。

## 安装与测试

```sh
npm ci --ignore-scripts
npm test
bash tests/test_cli.sh
```

测试不访问网络、不加载真实模型，也不把输入文本写入诊断日志。

## 运行时约定

把 `voxtype-zh-post` 放到可执行路径，并在 Voxtype 的输出后处理配置中引用它。需要标点恢复时，在 Voxtype 进程环境中设置 `VOXTYPE_PUNCTUATION_COMMAND`，其值为用户自行安装的适配程序路径。该程序通过标准输入和标准输出交换文字；本配套直接启动该程序，不经过 shell。用户自行负责选择模型、安装运行环境并维护适配程序。

项目不规定模型、模型来源或许可，也不把模型权重放入 Git。模型选择和安装由用户负责；请自行确认所选模型的使用条件。

## 已知边界

这个目录不携带模型权重、不复制本机脚本或本机路径，也不把识别文本写入临时文件。适配程序启动失败、超时、返回失败状态或没有输出时，会保留已完成简体转换的文字。真实模型效果需用户在目标机器上自行验收。
