# Voxtype 中文语音后处理

这是一个可选的 Voxtype 输出后处理配套。它从标准输入读入转写文本，并在失败时尽量保留可用文本；它不修改 Voxtype 的 Rust 识别路径。

## 当前状态

- 简体转换依赖 `opencc-js@1.4.2`。
- 标点推理运行时依赖 `sherpa-onnx-node@2.0.1`，但只有在本地已有标点模型时才需要模型推理。
- 没有模型时，功能应降级为简体转换和保守空格修整，不下载、不联网。
- 空输入直接原样输出。
- 模型推理失败、返回空结果或依赖不可用时，保留已经完成的简体转换；命令入口失败时回退到输入原文。

## 安装与测试

```sh
npm ci --ignore-scripts
npm test
bash tests/test_cli.sh
```

测试不访问网络、不加载真实模型，也不把输入文本写入诊断日志。

## 运行时约定

把 `voxtype-zh-post` 放到可执行路径，并在 Voxtype 的输出后处理配置中引用它。模型权重不放入 Git，也不由本目录的测试下载。

模型目录约定见 `model-source.md`。在模型来源和许可完成核实前，不应把模型下载、打包或再分发写进安装器。

## 已知边界

这个目录不携带模型权重、不复制本机脚本或本机路径，也不把识别文本写入临时文件。真实模型验收需要用户在目标机器上按已核实的正式来源准备模型后单独进行。
