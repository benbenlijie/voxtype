# 用户自选中文标点模型接入

## 项目与模型的边界

本项目不提供、不下载、不安装或再分发标点模型。用户自行选择模型、阅读其使用条件、安装运行环境，并准备一个适配程序。适配程序只需遵守以下输入输出约定：

1. 从标准输入读取 UTF-8 编码的文字。
2. 使用用户已安装并配置的本地模型补充标点。
3. 将处理结果以 UTF-8 编码写到标准输出。
4. 不将输入文字写入日志；模型或适配程序异常时，以非零状态退出。

通过 `VOXTYPE_PUNCTUATION_COMMAND` 指定适配程序的可执行文件路径。请配置为可信任的程序；本配套不会通过 shell 解释命令字符串。模型和适配程序的安装方式由用户自行决定。

适配程序超时、启动失败、返回非零状态或输出为空时，本配套回退到繁体转换后的文字，不影响 Voxtype 输出。
