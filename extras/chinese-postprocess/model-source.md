# 中文标点模型来源核对

## 需要固定的模型信息

发布前必须为 CT-Transformer 中文标点模型补齐以下信息：

1. 正式发布页或上游仓库的完整地址。
2. 确切模型名称、版本或提交号，以及 `model.onnx` / `model.int8.onnx` 的对应关系。
3. 权重文件的校验值。
4. 模型权重许可、模型卡许可、训练数据许可和再分发条件。
5. `sherpa-onnx-node` 的 `OfflinePunctuation` 配置与该模型格式的兼容证据。

## 当前核查结论

`sherpa-onnx-node@2.0.1` 的正式 npm 元数据和上游仓库可以核实，且其上游代码使用 Apache-2.0。它只是推理运行时，不等于具体 CT-Transformer 权重的许可。

本配套当前没有把某个模型 URL、模型版本或权重校验值写死，因为现有本机模型文件名不足以证明来源。**发布阻断：在上述模型信息全部核实前，不得下载、打包、安装或再分发该模型，也不得宣称中文标点恢复已经具备可发布模型。**

## 下载规则

模型来源核实后，下载实现必须满足：

- 只从已核实的正式地址下载；
- 支持显式 `--model-dir` 和用户提供的已核实地址；
- 下载后校验固定校验值；
- 不把远程脚本直接通过管道交给 shell；
- 权重仍留在本机模型目录，不进入 Git。

在阻断解除前，用户可以只使用简体转换和空格修整，不下载标点模型。
